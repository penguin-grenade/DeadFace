# Asset pipeline (Blender -> glTF -> Three.js)

Every model, texture and the level itself is generated by the Python scripts in
`blender/`. They run headless against the Blender API, either through a Blender
install or the `bpy` wheel:

```bash
blender -b -P blender/build_all.py -- [--size 1024] [--level]   # Blender 4.2+ (tested 5.0.1)
python3 blender/build_all.py [--size 1024] [--level]            # pip install bpy (Python 3.11)
python3 blender/make_mannequin.py --out public/models --preview /tmp/mq --views face,chest   # any single step
python3 blender/preview.py --glb public/models/pistol.glb --png /tmp/pistol.png            # Cycles render of any .glb
npm run level:bpy                                                # rebuild + bake the warehouse only
```

`build_all.py` bakes the tiling texture sets, builds every model, meshopt-compresses
the heavy ones and rewrites `public/assets.json`. `--level` also rebuilds the
warehouse and bakes its lightmap (tens of minutes on a CPU). The game only loads
what the manifest lists and falls back to procedural stand-ins for anything
missing, so a partial asset set still runs.

## Scripts

| Script | Output | How it's made |
| --- | --- | --- |
| `bake_textures.py` | `public/textures/<name>_{albedo,normal,roughness}.jpg` | Procedural node materials baked with Cycles. UVs are wrapped onto a 4D torus and fed to 4D noise, so every set tiles without seams. |
| `make_pistol.py` | `pistol.glb` | Hard-surface model: extruded/lofted profiles, exact booleans (ejection port, serrations, sight notch), 0.4–0.6 mm machined bevels with hardened normals, baked 2K PBR atlas. |
| `make_hands.py` | `arms.glb` | MIT WebXR hand mesh posed on the grip by a collision-aware grasp solver (joints curl until a phalanx touches the grip) with CCD thumbs, inflated into gloves with cuffs and sleeves, baked like the pistol. |
| `make_mannequin.py` | `mannequin.glb` | Training mannequin sculpted as a signed distance field, with an "analytic" high-to-low normal bake, bullet damage and a plate carrier. See below. |
| `make_props.py` | `steel_target.glb`, `can.glb`, `box_small.glb` | Hanging AR500 plate on a stand, soda can, cardboard box with the baked cardboard set. |
| `build_level.py` | `public/level/*` | The "Range 4" warehouse: geometry from `levelkit.py` and `level_props.py`, Cycles lightmap, wet/grime/specular-occlusion mask, HDR reflection probe, colliders, lights and gameplay spots in `level.json`. |
| `texbake.py` | | Atlas baking for hero assets: xatlas packing, Cycles ID / AO+edge+cavity / position / normal bakes, numpy compositing helpers, glTF-ready PBR material. |
| `sdf.py` | | Distance-field sculpting: primitives, smooth union/cut, lofts from measured sections, Surface Nets meshing, exact re-evaluation of the recorded operations. |
| `decals.py` | | Surface detail evaluated in 3D at baked texel positions: projector decals, bullet holes, duct tape, marker strokes, seams and stitching, rendered text. |
| `hardsurface.py`, `levelkit.py`, `level_props.py` | | Bevelled/boolean modelling helpers and the warehouse kit (racking, pallets, sandbags, lamps...). |
| `preview.py`, `common.py` | | Headless Cycles previews; shared scene, material, join and export helpers. |

## The mannequin, in more detail

The figure is built the way a character artist would, just with code standing
in for the sculpting brushes:

1. **Sculpt.** `body_field()` adds ellipsoids, capsules and rounded boxes into a
   3.5 mm voxel grid with smooth unions (`sdf.Field`). The face is a loft of
   measured horizontal sections (chin to forehead) with the nose, lips, eyes and
   ears added on top; the hands have jointed, curled fingers. The T-shirt, jeans,
   plate bags, cummerbund and straps are offset shells of the body field, with
   fabric folds from 3D noise, so they always sit on the body.
2. **Mesh.** Surface Nets turns each field into a mesh, which is relaxed
   (Corrective Smooth) and decimated. The MOLLE webbing and pull tabs are too
   thin for the grid and are built directly with bmesh.
3. **High poly for free.** The field records every operation, so it can be
   evaluated exactly at any point, including detail-only operations that are too
   fine for the grid (lips, mouth line, eyelids, nostrils, ear folds). Each
   texel is carried along the mesh normal onto that exact surface, like the cage
   rays of a conventional bake, and the exact gradient there is the high-poly
   normal: no separate high-poly mesh to sculpt, store or keep in sync.
4. **Damage and wear.** `shoot()` ray casts 30-odd hits against the figure;
   `paint_marks()` adds duct tape over some holes and marker circles and tallies
   the way range staff do. All of it lives in 3D (projector decals), so it
   crosses UV seams and object boundaries cleanly.
5. **Composite.** Per material, numpy layers evaluate at every texel's baked
   position: paint with chips down to filler and glass fibre, grime in the
   cavities, seams and stitch rows as distance functions, denim twill and fades,
   hook-and-loop, a name tape and a stencil rendered from text. Each layer
   returns a height function that is differentiated in 3D into the detail normal.
   Where that normal turns sharply from one texel to the next (hole rims, the
   mouth line, stitches) it is supersampled over the texel's footprint, so fine
   creases don't alias into staircases along the texel grid.
6. **Bake.** The detail normals go into a Cycles tangent-space normal bake
   (plus a micro bump per material), and base colour and ORM are written as a
   2K atlas. The export carries tangents so the game uses the same basis.

Rebuild with `python3 blender/make_mannequin.py --out public/models`, then
compress with `npx @gltf-transform/cli meshopt` (build_all does both). `--no-bake`
with `--preview DIR --views face,chest,backpack,profile` is a 2-minute
geometry-only check.

## Conventions the game relies on

- **Units:** metres. **Axes:** model with **+Y forward, +Z up** (the mannequin
  faces **-Y**); the glTF exporter turns that into three.js -Z forward, +Y up.
- **Weapon nodes** (found by name in `src/game/weapon.ts`): `Slide` (origin at
  the weapon origin, the game offsets its local Z to cycle it), and the empties
  `Muzzle`, `Ejection`, `LightMount`. **Arms** share the pistol's origin so both
  parent to one viewmodel pivot.
- **Mannequin:** origin at the floor under the stand, about 1.85 m tall on a
  12 mm steel base plate. The hit colliders in `src/game/targets.ts` are fitted
  to this model part by part (head, neck, torso, arms, legs, stand); a hit on a
  collider is refined against the visible mesh, so gaps between the colliders
  and the model don't swallow or invent hits.
- **Steel target:** origin at the plate centre, face normal along -Y, hanging
  0.45 m below the crossbar. **Props** are centred on their origin.
- **Tiling textures:** 1024² JPEG, albedo sRGB, OpenGL (+Y) normals, roughness in
  every channel. **Hero atlases:** 2K `basecolor` (sRGB), `orm` (R occlusion, G
  roughness, B metalness) and `normal`, embedded in the .glb.
- **Level:** `level.glb` has one mesh per material with `TEXCOORD_1` lightmap
  UVs; `level.json` carries materials, colliders, lamps (drawn in real time,
  their bounce comes from the lightmap), the probe box and the spawn/target spots.

## Compression and hosting

Large meshes are quantised and meshopt-compressed (`@gltf-transform/cli meshopt`);
the game registers `MeshoptDecoder`, so plain and compressed files both load.
`tools/artifact.mjs` converts .glb and .hdr files into JSON-wrapped variants for
static hosts that only serve common web file types.

## Swapping in real assets

- **Scanned materials:** drop CC0 sets (ambientCG, Poly Haven) into
  `public/textures` with the same names and make sure the stem is in `assets.json`.
- **Hand-made models:** export glTF 2.0 with the node names above into
  `public/models` and add the stem to `assets.json`. A replacement mannequin
  should keep the origin and height, or the colliders in `targets.ts` need refitting.
- **Skinned characters:** export with an armature and actions, load with
  `GLTFLoader`, play clips with `THREE.AnimationMixer` (not wired up yet).
